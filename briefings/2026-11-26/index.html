  • OpenTelemetry Collector v0.166.0 adds gRPC address-list shuffling, listener middleware extensions and FIPS 140-3 startup logging

    open-telemetry/opentelemetry-collector - released 23 Nov 2026 22:26 UTC

    The release adds the pick_first.shuffle_address_list option for gRPC clients that use the pick_first balancer, so clients resolving the same address list no longer all connect to the first address; the option is off by default and implements gRFC A62. Listener middleware extensions can now create HTTP and gRPC server listeners, and the Collector reports in its startup log line whether it is running in FIPS 140-3 mode.

  • OpenTelemetry Specification v1.63.0 marks environment variables as stable context propagation carriers and adds a traces data model

    open-telemetry/opentelemetry-specification - released 23 Nov 2026 17:25 UTC

    Release 1.63.0 stabilizes environment variables as context propagation carriers and adds the traces data model to the specification. It introduces a development span type with an optional span creation parameter, ReadableSpan access and SDK syntax validation, and allows an exception to the finite upper bound on exporter Export calls for synchronous output through APIs without deadline or cancellation support.

  • SigNoz v0.152.0 removes the saved-view v1 APIs and starts moving log bodies to native JSON storage

    SigNoz/signoz - released 26 Nov 2026 09:28 UTC

    The release deletes the saved view v1 APIs, deprecated since v0.137.0, so callers using them directly have to migrate to v2. Log bodies move to native JSON storage with dual ingestion, which the project says requires additional collector CPU and memory, ClickHouse CPU and log disk capacity before the upgrade.

  • OpenObserve v1.2.0 rebuilds dashboards, ships a second-generation metrics explorer and adds product analytics and continuous profiling

    openobserve/openobserve - released 24 Nov 2026 12:39 UTC

    More than 900 changes from 40 contributors. Dashboards gain public read-only links, a TV mode, a layout editor with undo, live panel preview and four new panel types; the metrics explorer v2 can create alerts from any chart, compare periods, forecast, write formulas and use Prometheus 3.x functions. Product analytics and continuous profiling are included out of the box alongside dozens of alerting improvements.

  • Grafana MCP v2.4.0 adds notebook tools and opt-in AWS X-Ray trace tooling

    grafana/mcp-grafana - released 24 Nov 2026 10:01 UTC

    The release adds tools for the Grafana 13.3 notebooks preview: list, search, get by UID, render to PDF, create, update and delete. The update tool keeps the notebook metadata and checks the resourceVersion it was read at, so a concurrent edit fails instead of being overwritten. An opt-in xray category adds search_xray_traces and get_xray_trace, the latter returning a trace as a tree of segments with timings and HTTP status codes.

  • Grafana v13.3.2 fixes two CVEs and preserves folder identities during provisioning

    grafana/grafana - released 24 Nov 2026 17:58 UTC

    The patch release fixes CVE-2026-107561 and CVE-2026-88960. Its provisioning change keeps existing folder identities when children are created instead of regenerating them, so dashboards and folders produced by the same provisioning job keep stable identifiers across runs.

  • Grafana Beyla v3.44.0 adds GPU metrics collection to the eBPF auto-instrumentation

    grafana/beyla - released 25 Nov 2026 10:27 UTC

    Beyla v3.44.0 adds GPU metrics collection and export, and makes server.address and server.port opt-in on HTTP request duration and body size so those labels are no longer emitted by default. It also carries upstream changes from opentelemetry-ebpf-instrumentation, including Go channel links moved to runtime configuration, preserved custom query-parameter redaction in Config v2 and runtime.goexit1-based Go exception cleanup.

  • Prometheus Alertmanager v0.35.1 raises the HTTP server idle timeout so alert deliveries are not cut off

    prometheus/alertmanager - released 24 Nov 2026 22:47 UTC

    The fix raises the Alertmanager HTTP server idle timeout from 90 seconds to 6 minutes, outlasting the 5-minute client idle timeout used by Prometheus, so alert POSTs are no longer failed by connections closed on the server side.

Agentic AI papers

8 items

  • ShellBench: What Matters More for AI Agents, Models, or Harness for Everyday Tasks

    arXiv:2611.32946 - listed 25 Nov 2026

    ShellBench is a benchmark of 100 day-to-day tasks built from more than 10 million user requests, each set in a realistic workspace with messy files and competing data sources, and graded for both correctness and safety. The authors evaluate 12 models across five agent harnesses at three reasoning levels for 53,100 rollouts, 20% of them on tasks released publicly. Model choice affected performance more than harness choice, but the three leading models were separated by only 1.1 percentage points, and the cheapest leading model passed 61.4% of attempts at roughly one-sixth of the cost of the most expensive one.

  • Delegent: A Multi-Agent Harness That Reduces Cost without Sacrificing Performance

    arXiv:2611.33098 - listed 25 Nov 2026

    Delegent is a harness built on Claude Code in which the frontier model stays in charge of every task but hands focused subtasks, such as investigating code, running tests and searching a corpus, to small language model subagents running on hardware the user already owns. The authors report cost reductions of about 67% on long-horizon coding tasks and 59% on agentic search against the frontier-only baseline, and distinguish the design from cascades and model routers, which assign whole tasks to the cheaper model.

  • RECAP: Training Long-horizon LLM Agents with Context Compaction

    arXiv:2611.31258 - listed 25 Nov 2026

    RECAP is a reinforcement-learning framework that learns context compaction jointly with the agent policy, on the principle that a summary should preserve the behaviour the original interaction history would have induced. The paper formalises that as a behaviour-distortion objective and shows its gradient decomposes into two complementary learning signals, one for the summariser and one for the policy, which addresses the fact that a compacted summary changes task success over many subsequent interactions.

  • ExpGuard: Guarding Long-Horizon LLM Agents against Corrupted Experience

    arXiv:2611.32085 - listed 25 Nov 2026

    ExpGuard addresses the risk that long-horizon agents distil misleading or adversarial instructions from past trajectories into reusable experience that then persists across tasks. It models provenance and execution dependencies before an experience is reused, learns task-conditioned risk from trajectory outcomes, and repairs risky experiences at online inference through retrieval-triggered assessment.

  • When Tools Fail, Agents Fabricate: Silent Failure and Verification-First Oversight in Tool-Using LLM Agents

    arXiv:2611.28341 - listed 24 Nov 2026

    Using RetryRealistic, a sandboxed testbed with controlled fault injection over 8 tools, 9 fault types and 30 multi-step tasks, the authors run 2,100 faulted runs of four agents against ground truth. Recovery was unreliable at between 19% and 68% correct, and frequently silent: 6% to 26% of runs ended in a confident fabrication, a wrong answer asserted as fact. The failure mode was governed more by the fault type than by the model, which argues for verification-first oversight rather than model scaling.

  • From Local Errors to System Failures: Modeling and Benchmarking Error Propagation in Multi-Agent LLM Systems

    arXiv:2611.31063 - listed 24 Nov 2026

    REPA is a structural model that links measured local agent responses to system-level error propagation in multi-agent systems, estimating input assembly and agent processing separately across error channels and relating local modelling error to endpoint prediction error. Across three Qwen base models, six multi-agent workflows and ten knowledge and reasoning settings in the new ErrPropBench-10 benchmark, REPA reaches a mean condition-level Spearman correlation of 0.84 against 0.47 for direct regression, with a retrieval gain of about 19 points.

  • Maco-RL: Scaling Agent Capabilities with Mixed-Task Reinforcement Learning

    arXiv:2611.34703 - listed 26 Nov 2026

    Maco-RL scales mixed-task reinforcement learning, where one policy is trained across domains instead of a specialist per domain and no separate distillation stage is needed. It uses a quota-based scheduler for asynchronous rollouts across task domains to balance gradient contributions and limit off-policy effects, and adds Tri-Buffer Sampling to allocate rollout compute, targeting stable training and continual domain expansion.

  • MeterRouter: Budget-Aware Dynamic Routing for Multi-Agent Systems

    arXiv:2611.34327 - listed 26 Nov 2026

    MeterRouter treats cost as an explicit optimisation constraint for multi-agent systems, incrementally synthesising a collaboration graph per query by choosing how many agents to recruit, which model each should get and how they communicate. The authors report accuracy comparable to assigning a large model to every agent at about 82% lower cost, and note that a fixed accuracy-cost preference cannot express what a particular query is worth.

    Dwarkesh Podcast - 24 Nov 2026 21:45 UTC

  • Warp bets on the software factory

    Changelog Interviews #693 - 24 Nov 2026 20:00 UTC

    Warp founder Zach Lloyd presents Warp Factories, open infrastructure he bills as the successor to CI/CD for agent-driven development, covering factory-as-code, what an agent trace contains and why self-improving systems drift.   • What Should a Lab Do Before It Feeds Its Data to AI? with Loren Perelman

    The Artificial Intelligence Podcast - 24 Nov 2026 14:00 UTC
