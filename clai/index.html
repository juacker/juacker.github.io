What it is

An agent team, in a desktop app

CLAI organizes work into workspaces. Each has a configurable main agent that chats with you, uses tools, delegates to helper agents, persists context, and can run on a schedule. The Fleet view supervises everything.

Workspace-local agent teams

Add helpers like a Code Reviewer or SoW Tracker, each with their own prompts, skills, MCP servers, providers, and execution policy. The main agent calls them as tools.

MCP-native tools

Configure MCP servers once in Settings, then attach them per workspace or per agent. Streamable HTTP and stdio transports, with OAuth sign-in for remote servers.

Local execution sandbox

Per-agent filesystem grants and three shell modes — Off, Restricted (allowed command prefixes only), and Full — keep agent actions scoped.

Multiple providers

OpenAI- and Anthropic-compatible API connections, plus local CLI agents like Claude Code, OpenAI Codex, and OpenCode. Each agent picks its own.

Inspectable tasks

Delegated work streams a live transcript — the helper agent's full conversation, tool calls, and verdict — so nothing happens in a black box.

Memory & artifacts

Agents persist findings to the workspace directory. The drawer surfaces memories and artifacts with read-only previews — rendered markdown, pretty JSON, multi-file HTML.

Getting started

Up and running in minutes

Download a build, connect a provider, and start a workspace.

Add a provider

Connect an API provider, or point CLAI at a local CLI agent — supported ones are auto-detected.

Add MCP servers

Optional. Register local or remote MCP servers for external tools, with one-click OAuth sign-in.

Create a workspace

From the Fleet view. Attach a provider, MCP servers, and skills from its settings.

Chat & delegate

Talk to the main agent and add helper agents from the Agents drawer when you need them.

🔐 OAuth client identity

This site also hosts CLAI's Client ID Metadata Document (CIMD) for MCP OAuth at https://juacker.github.io/clai/auth/client-metadata.json. That URL is CLAI's stable, public OAuth client_id — used when you sign in to remote MCP servers. No client secret, PKCE only.
